How it works

This mirrors the in-game chemistry menu. Pick an administration method, the start and end halves of your reactant compound, a synthesis temperature, and an optional label. Unlike cooking, the drug types and chemicals are fixed (not tied to any skill), so the lists are built in.

The Command to type box gives you the inputs one per line: make drug, then the menu numbers for each choice, then yes to confirm. A blank label becomes a single . to keep the drug unlabeled. The breakdown under the command shows which line maps to which choice, so you can confirm it matches the in-game flow.

Saved recipes and their notes stay in this browser. The note is yours; it's never part of the command.
